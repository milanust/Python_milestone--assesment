# Student Marks Management System

## Problem Statement
Develop a Python application to manage student marks, calculate totals, averages, grades and display reports.

## Approach
1. Accept student details.
2. Store data using dictionaries inside a list.
3. Calculate total, average, grade, and result.
4. Find highest scoring student.
5. Find students scoring above 75 average using list comprehension.

## How to Run

python main.py

## Python Concepts Used

- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- List Comprehension
- Lambda Function
