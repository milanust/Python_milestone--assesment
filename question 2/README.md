 Employee File Management System

## Problem Statement

Create a Python application that stores employee details in a file and generates reports.

## Approach

1. Create Employee class.
2. Store employee data in employees.txt.
3. Read data using file handling.
4. Display all employees.
5. Find employees with salary above 50000.
6. Find highest salary employee.
7. Count employees by role.
8. Handle file exceptions.

## How to Run

python main.py

## Python Concepts Used

- Classes and Objects
- Constructor (__init__)
- Methods
- File Handling
- Exception Handling
- Context Manager (with open)
- Lists
- Dictionaries
- Functions
- List Comprehension
